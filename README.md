# School Management

School Management is a C project I built independently while preparing for the CSCA48 midterm. The goal was to apply Chapters 1–3 of the course notes in a real program rather than just reading them.

The system manages student, teacher, and parent records, with a focus on:

- Pointers and pointer-based data manipulation
- Linked lists for storing and traversing user records
- Compound data types (CDTs) using structs
- Dynamic memory allocation and deallocation (malloc/free)
